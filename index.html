P3

AI演进历程

2010s

传统AI与深度学习

基于规则的专家系统，CNN/RNN 等神经网络架构在图像和语音领域取得突破。2012 年 AlexNet 在 ImageNet 竞赛中夺冠，标志着深度学习时代的到来。

2017

Transformer架构

Google 发表《Attention is All You Need》论文，自注意力机制彻底改变 NLP 领域，并成为后续大语言模型的基础。

2018-2020

预训练模型时代

BERT、GPT-2 等预训练模型出现，通过大规模无监督学习获得强大语言理解能力，少样本学习能力开始显现。

2020-2022

大语言模型时代

GPT-3、ChatGPT 等模型涌现，Scaling Law 被验证，模型具备推理、代码、翻译等跨领域能力。

2023

Agent概念兴起

AutoGPT 等自主智能体出现，LangChain 生态繁荣，AI 开始具备工具使用能力，RAG 技术成熟。

2024+

智能体与多模态

多 Agent 协作成为主流，视觉、语音、文本协同工作，具身智能开始探索物理世界。

P4

什么是大语言模型

LLM = 海量数据 + 巨量参数 + 强大算力
核心本质

大语言模型本质上是一个“下一个 Token 的概率预测机”。通过 Scaling Law，当数据量、参数量和算力足够大时，模型能力会产生质的飞跃，涌现出理解、推理、生成等复杂能力。

神经网络由输入层、权重层、激活层和输出层组成。输入层接收原始数据，权重层进行加权处理，激活层引入非线性变换，输出层产生最终结果。

P7

LLM的能力边界

擅长领域

✓ 文本生成与内容创作

✓ 代码编写与调试辅助

✓ 逻辑推理与问题分析

需要补强

✗ 实时信息获取能力

✗ 精确执行操作能力

✗ 私有知识整合能力

✗ 幻觉问题需要解决

结论

LLM 是一个极其强大的“大脑”，但缺乏“手脚”和“实时记忆”，这就是为什么我们需要智能体。

P8

定义对比：LLM vs Agent

LLM

仅仅是一个强大的大脑

  • 可以进行丰富的对话交流
  • 具备强大的决策和推理能力
  • 理解复杂概念和问题
  • 但是没有肢体，无法实际行动
  • 无法直接操作工具或环境
Agent

大脑 + 钢铁般的躯体 + 工具技能

  • 同样具备强大的 LLM 大脑
  • 拥有执行能力和环境感知能力
  • 配备知识库、API、数据库等工具
  • 能够做出决策并独立执行
  • 完成复杂的多步骤任务

P17-P18

RAG检索增强生成技术

什么是RAG？

RAG 是一种将信息检索与文本生成相结合的技术。它先从知识库中检索相关信息，再将检索内容作为上下文提供给 LLM 回答，从而提升准确性和可信度，减少幻觉。

P15-P16

Skills技能系统详解

什么是Skills？

Skills 是智能体的“手脚”，它们是可重用的功能模块，让 Agent 能够执行具体任务。每个 Skill 都包含输入参数、执行逻辑和输出结果，可以独立调用也可以组合使用。

模块化设计，易于维护和扩展 可重用性，同一 Skill 可用于多个场景 标准化接口，方便集成外部 API 安全可控，权限可细粒度管理
